## Number Guessing Game

A simple Python game where the computer randomly selects a number between 1 and 100. The player has 7 attempts to guess the correct number.
### **Features**
- Random number generation
- 7 attempts to guess
- *Hints:** Too High or Too Low
- Win or Game Over messages
### **Technologies**
- Python
- Random module
- Functions and conditional statements
- Recursion
